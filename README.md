# **TrackIt**

🎯 **TrackIt** — минималистичное и удобное приложение для ведения счёта в настольных играх. Поддерживает несколько режимов игры, управление игроками, историю партий, настраиваемые темы и работу офлайн.

---

## 🆕 Что нового в версии 4.0

### 🔧 Архитектура и стабильность
- **Система архивирования игроков** — удалённые игроки больше не теряются. Они автоматически архивируются и могут быть восстановлены при повторном добавлении
- **Фиксация коллизий ID** — исправлена ошибка, когда разные русские имена одинаковой длины получали идентичный ID. Теперь используется стабильный хеш по имени
- **Миграции данных** — автоматическое преобразование старых данных в новый формат без потери информации (4 этапа миграции)
- **Восстановление из архива** — при добавлении игрока с известным именем восстанавливается его ID, но аватар остаётся случайным

### 🎨 UI/UX улучшения
- **Новый лоадер** — glass-эффект с blur и saturate фильтрами, гладкое исчезновение (настраивается на 3 секунды)
- **Редактирование игроков** — новая страница для массового управления:
  - ✏️ Переименование игрока (обновляется везде: комнаты, история, архив)
  - 🔗 Слияние дублей игроков (объединяются очки и история)
  - Видно количество очков в каждой комнате
- **Улучшенная история** — автоматический пересчёт всех игр по новой правильной логике режимов
- **Избранные комнаты** — ❤️ пометь комнаты, они будут вверху списка

### ⚡ Производительность и кэширование
- **Service Worker v4.0** — три адаптивные стратегии:
  - **Аватары** → Cache First (быстро + фоновое обновление)
  - **HTML** → Network First (свежий контент + офлайн)
  - **Остальное** → Stale-While-Revalidate (мгновенно + обновление в фоне)
- **Фаллбэк на главную** — при полном офлайне приложение всё равно загружается
- **Background Sync** — автосинхронизация истории при возврате онлайн
- **Оптимизированная анимация** — плавное исчезновение лоадера без рывков

### 🔐 Безопасность и надёжность
- **XSS защита** — экранирование кавычек и спецсимволов в именах игроков
- **Обработка ошибок** — graceful degradation при ошибках localStorage
- **Валидация структуры** — проверка целостности импортированных данных

## 🎮 Режимы игры

### 🔄 Обнуление
Счёт обнуляется, если ровно равен максимуму. Если больше — это проигрыш.
- Победители: первые 3 игрока (с наименьшим счётом)
- Проигравший: тот, кто превысил лимит
- Медали: 🥇 🥈 🥉 для топ-3

### 💀 Проигрыш
Тот, кто первым набирает максимум очков — проигрывает.
- Победители: первые 3 игрока (с наименьшим счётом)
- Проигравший: тот, кто набрал максимум
- Медали: 🥇 🥈 🥉 для топ-3

### 🎯 Цель
Тот, кто первым достигает максимума очков — побеждает.
- Победитель: один (с наибольшим счётом)
- Проигравшие: все остальные
- Медали: 🥇 для победителя, 💀 для остальных

## 📊 Архитектура данных

### GameState (управление состоянием)
```javascript
{
  rooms: Array,           // Активные комнаты с игроками
  gameHistory: Array,     // Архив всех сыгранных партий
  recentPlayers: Array,   // 10 последних имён (для быстрого выбора)
  allPlayers: Array,      // АРХИВ всех когда-либо игроков (из удалённых комнат)
  currentRoomIndex: Number // Текущая открытая комната
}
```

### Структура игрока
```javascript
{
  id: "player_hash",      // Стабильный ID на основе имени
  name: "Иван",           // Имя
  score: 42,              // Текущий счёт
  avatar: "ava00.png",    // Случайная аватарка
  history: [              // История ходов
    { value: 10, timestamp: "2026-08-18T10:30:00Z" },
    { value: -5, timestamp: "2026-08-18T10:31:00Z" },
    { value: "🔄", timestamp: "2026-08-18T10:32:00Z" } // Обнуление
  ]
}
```

### Миграции данных
- **Миграция 1** — генерация ID для игроков без них
- **Миграция 2** — объединение дублей ID (одинаковые имена)
- **Миграция 3** — разведение коллизий ID (коллизии из-за кириллицы)
- **Миграция 4** — применение карты коллизий к истории и архиву

## 🐛 Известные исправления v4.0

| Проблема | Симптом | Решение |
|----------|---------|---------|
| Удаление игроков | Игроки теряются навсегда | Архивирование в allPlayers |
| Коллизии ID | Русские имена получали один ID | Стабильный хеш по имени |
| Потеря при удалении комнаты | Все игроки в комнате исчезали | Архивирование перед удалением |
| Восстановление из архива | Аватар менялся каждый раз | Генерируется новый (не из архива) |
| История не пересчитывалась | Старая логика режимов | Автоматический пересчёт при загрузке |

## 🚦 Обновление с предыдущих версий

Если ты используешь TrackIt < v4.0:

1. **Резервная копия** (обязательно!)
   ```javascript
   // Откройте DevTools (F12) → Console и выполните:
   const backup = JSON.stringify(gameState);
   console.log(backup); // Скопируй в текстовый файл
   ```

2. **Очистка кэша** (если видишь баги)
   ```javascript
   localStorage.clear();
   caches.keys().then(names => 
     Promise.all(names.map(n => caches.delete(n)))
   );
   location.reload(true);
   ```

3. **Миграция произойдёт автоматически** при первой загрузке v4.0
